# トラブル対応

## 画面のデザインが崩れる・CSSが読み込まれない

- インストール時のベースURLに末尾の`/`があるか確認する
- サブディレクトリ設置では、そのパスまで含まれているか確認する
- `/assets/app.css`へ直接アクセスできるか確認する
- `/index.php/assets/app.css`のようなURLになっていないか確認する
- `.htaccess`とURL書き換えを確認する
- サーバーキャッシュを無効にして再確認する

## HTTPSまたはベースURLのエラー

- SSL設定の反映が完了するまで待つ
- 証明書エラーのない`https://` URLでインストーラーを開く
- ベースURLのドメイン、サブディレクトリ、末尾`/`を設置先と一致させる
- HTTPからHTTPSへの転送でパスやクエリが失われていないか確認する

## 環境診断が失敗する

- PHP 8.3以上を選択する
- 必須PHP拡張を有効にする
- PDO SQLiteとSQLite3がともに3.26.0以上か確認する
- 非公開領域が絶対パスで、公開領域外にあるか確認する
- 非公開領域の作成・書込・読取・削除権限を確認する
- SQLiteのWAL、JSON、UPSERT、外部キー、ロック診断のどれが失敗したか確認する

診断用ファイルが残った場合は、対象パスを確認してから削除し、原因を解消して再診断してください。

## 管理者がログインできない

- メールアドレスとパスワードの前後に空白がないか確認する
- ログイン試行制限中は時間を置く
- 復旧キーがある場合はパスワード再設定を使う
- 両方を失った場合はSSHから`php bin/reset-admin-credentials.php`を実行する
- CLIのPHPが8.3以上か確認する。XServerではWeb版とCLI既定版が異なる場合があります

## 復旧キーが使えない

復旧キーは再設定のたびに更新され、以前のキーは無効になります。最新のキーを使用してください。画面に再表示する機能はありません。

## スポットを取得できない・初参加画面へ戻る

- QRを最初と同じ端末・通常ブラウザで開く
- iPhoneのコードスキャナーを使わず、標準カメラからSafariで開く
- プライベートブラウズ、アプリ内ブラウザを使わない
- Cookieが無効または削除されていないか確認する
- イベント期間、一時停止、スポット停止状態を確認する
- HTTP 419が出た場合は案内に従い、画面を開き直して送信する

Cookieを失った参加履歴を、別のCookieへ統合する機能はありません。

## 古いQRが使えない

QR再発行後は古いQRが無効です。管理画面から新しいQRを印刷して交換してください。環境移転でベースURLが変わった場合も、イベント入口と全スポットQRを交換します。

## PDFを生成できない・文字が欠ける

- `dom`等の必須拡張と同梱`vendor/`が揃っているか確認する
- Noto Sans JPのフォントファイルとライセンスファイルを確認する
- 非公開領域のフォントキャッシュへ書き込めるか確認する
- イベント名とスポット名が50文字以内か確認する
- PHPのメモリ・実行時間制限とサーバーログを確認する

## CSVが文字化けする・内容が違う

- Excel等でUTF-8のCSVとして読み込む
- 応募者だけ必要な場合は「応募者CSV」を使う
- 未応募を含む参加状況は「全参加者CSV」を使う
- CSVを第三者へ送る前に個人情報を確認する

## バックアップを作成・検証できない

- 現在の管理者パスワードを確認する
- `zip`、`fileinfo`、SQLite拡張を確認する
- アップロード上限が100MB以上か確認する
- この製品が作成した未加工のZIPを使用する
- ZIPの破損、形式、ハッシュ、必須テーブル、外部キー、件数が検査されます
- 「QRコードの秘密鍵が現在の環境と異なります」と出た場合は、別環境のバックアップを稼働中環境へ誤って上書きしようとしていないか確認する

## 復元後にログインできない

復元後は、バックアップ作成時点の管理者メールアドレスとパスワードを使用します。復元前の認証情報ではログインできない場合があります。

## HTTP 419

フォームの有効期限切れ、別画面の操作、管理者と参加者画面を同じセッションで操作した場合等に表示されます。入力内容を確認し、案内された画面を開き直して再送信してください。何度も起きる場合はCookieとサーバーキャッシュ設定を確認します。

## HTTP 429

短時間のアクセスが上限を超えています。連続読み取りや再読み込みを止め、少し待ってから再試行してください。攻撃や自動アクセスが疑われる場合はアクセスログを確認します。

## HTTP 503

イベントが一時停止中、または一時的に処理できない状態です。管理者はイベント設定とサーバーログを確認し、原因を解消してから一時停止を解除します。

## PHPの警告や内部情報がブラウザに出る

本番環境の`display_errors`を`Off`にします。`log_errors`は`On`を維持し、公開領域外のPHPログを確認してください。ログを共有するときは、パス、メールアドレス、Cookie、トークン、応募情報等を伏せてください。
