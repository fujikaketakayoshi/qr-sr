# アンインストール手順

アンインストールすると、イベント、スポット、参加履歴、応募、操作ログを利用できなくなります。削除前に必要なデータを確認してください。

## 1. 削除前の保存

1. 「応募者CSV」を保存する
2. 必要なら「全参加者CSV」を保存する
3. 管理画面から最終バックアップZIPを作成する
4. バックアップを別の安全な場所へ移し、復元に必要な管理者情報を確認する
5. 個人情報の保管期限、利用目的、廃棄方法を確認する

不要な個人情報を「念のため」で保管し続けないでください。

## 2. 設置場所の確認

削除対象を、推測ではなく実際のパスで確認します。

- アプリの公開ディレクトリ
- インストール時に指定した非公開領域
- 手元やサーバー上に保存したバックアップZIPとCSV
- このアプリのために追加したcron
- 一時ファイルや展開元ZIP

同じドメインに別サイトがある場合は、そのファイルや`.htaccess`、`.user.ini`を削除しないでください。

## 3. 公開領域の削除

メンテナンス中であることを案内したうえで、ファイルマネージャ、FTPまたはSSHから、このアプリの公開ファイルだけを削除します。

XServer等が生成した`.htaccess`や`.user.ini`をアプリ設置前から利用していた場合は、退避した内容と照合し、アプリ用に追加した行だけを取り除きます。ドメイン直下を丸ごと削除しないでください。

## 4. 非公開領域の削除

非公開領域には次が含まれます。

- 設定ファイル
- SQLite DB、WAL、SHM
- ログ
- バックアップ処理用一時ファイル
- PDFフォントキャッシュ

必要なバックアップを別の場所へ保存したことを確認してから、インストール時に指定した非公開領域だけを削除します。削除後は元に戻せません。

## 5. cronと残存ファイル

- このアプリ専用のcronがある場合だけ削除する
- サーバーと手元の展開元ZIP、一時バックアップ、CSVを確認する
- 公開URLからアプリ、設定、DB、ディレクトリ一覧へアクセスできないことを確認する
- サーバーのゴミ箱や自動バックアップに残る期間を確認する

## 6. SSL、ドメイン、サーバー契約

他のサイトやメールで利用していないことを確認したうえで、不要ならサブドメイン、DNSレコード、SSL設定を整理します。親ドメインやサーバー契約の解約は、他の用途への影響を確認してから行ってください。

## 7. 完了確認

- 公開URLにアプリが表示されない
- 非公開領域が削除されている
- 不要なバックアップZIPとCSVが残っていない
- 個人情報が公開領域、ログ、一時ファイルに残っていない
- 他サイト、メール、既存`.htaccess`へ影響がない

削除後に再開する可能性がある場合でも、バックアップZIPと復元情報の管理責任は利用者にあります。
