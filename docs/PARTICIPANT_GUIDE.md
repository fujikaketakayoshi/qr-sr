# 参加者向け案内ガイド

この文書は、イベント主催者が参加者へ案内する内容のひな形です。問い合わせ先やイベント固有の条件を追記して使用してください。

## 参加方法

1. イベント入口またはスポットのQRコードをスマートフォンの標準カメラで読み取ります
2. SafariやChrome等の通常ブラウザで開きます
3. イベント入口では台紙が開き、スポットではスタンプの取得結果が表示されます。ニックネームは台紙で任意に登録できます。登録後の変更はできません。未入力でも取得・達成・応募まで進めます
4. 同じブラウザで各スポットのQRコードを読み取ります
5. 必要数を集めると達成です
6. 応募があるイベントでは、締切までに応募フォームを送信します

## 必ず確認してください

- 参加中は同じスマートフォン・同じ通常ブラウザを使ってください
- iPhoneでは標準カメラからSafariで開いてください
- iPhoneのコントロールセンターにある「コードスキャナー」は使わないでください
- SafariのプライベートブラウズやChromeのシークレットモードは使わないでください
- LINE、Instagram等のアプリ内ブラウザを避けてください
- Cookieを削除しないでください

参加履歴はブラウザCookieに保存された識別情報とサーバー上の記録を組み合わせて管理します。Cookie削除、別ブラウザ、プライベートブラウズ、機種変更では、以前の履歴を引き継げません。

QRコードの読み取りとページ表示には通信料がかかる場合があります。

## 応募について

達成後、応募受付中であれば台紙画面と達成したスポット画面に応募フォームへの案内が表示されます。送信後は応募番号が表示されます。締切前かつ受付中であれば「応募内容を確認・編集する」から内容を確認できます。

個人情報を入力する前に、画面に表示される利用目的を確認し、「個人情報の取り扱いに同意する」にチェックしてください。

## 入口掲示用の短い案内

```text
QRコードを標準カメラで読み取り、SafariやChromeなどの通常ブラウザで開いてください。
参加中は同じ端末・同じブラウザを使い、Cookieを削除しないでください。
iPhoneの「コードスキャナー」、プライベートブラウズ、アプリ内ブラウザは使用しないでください。
通信料は参加者の負担となる場合があります。
問い合わせ先: ____________________
```

## スポット掲示用の短い案内

```text
このQRコードを標準カメラで読み取り、参加時と同じ通常ブラウザで開いてください。
iPhoneの「コードスキャナー」やアプリ内ブラウザは使用しないでください。
読み取り後、スポットを取得した表示を確認してください。
問い合わせ先: ____________________
```

## 問い合わせ時に確認すること

- 使用している端末
- iOS／Androidのバージョン
- QRコードを読み取ったアプリ
- 開いたブラウザ
- Cookie削除やブラウザ変更の有無
- 表示されたメッセージと発生日時

パスワード、復旧キー、応募内容等の秘密情報を、第三者が見られる場所へ書かないでください。
