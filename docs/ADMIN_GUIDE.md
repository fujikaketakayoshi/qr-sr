# 管理者ガイド

## 1. ログインと認証情報

設置URLの`/admin/`からログインします。使用後は「ログアウト」を押してください。

パスワードを忘れた場合は、ログイン画面の再設定機能で、管理者メールアドレス、保存済みの復旧キー、新しいパスワードを入力します。再設定後は新しい復旧キーが一度だけ表示され、以前のキーとログイン中の管理者セッションは無効になります。

パスワードと復旧キーの両方を失った場合は、サーバーへSSH接続して次を実行します。イベント、参加者、応募データは削除されません。

```console
php bin/reset-admin-credentials.php
```

パスワードをコマンド引数へ書かないでください。

## 2. イベント設定

「イベント設定」で次を指定します。

- イベント名、説明
- 開始日時、終了日時
- 達成に必要なスタンプ数（1～20）
- 参加者向け注意事項
- 達成時メッセージ
- 緊急時の一時停止と案内

達成数は登録済みスポット数以下にしてください。一時停止中は新規参加やスタンプ取得等を止められます。障害対応後は停止を解除し、参加者画面を確認してください。

## 3. 応募設定

「応募設定」で応募受付の有効・無効、締切、利用目的、氏名・メールアドレス・住所・電話番号の使用有無と必須・任意を設定します。

- 締切が空欄の場合はイベント終了日時を使います
- 応募締切はイベント終了日時以後に設定します
- 応募を有効にする場合は、応募項目を1つ以上使用します
- 個人情報の利用目的を参加者へ表示します
- 応募停止中と締切後は内容を変更できません

イベント終了日時を変更する場合は、設定済みの応募締切との前後関係も確認してください。

## 4. スポット管理

「スポット管理」で追加、編集、並べ替え、停止・再開、削除を行います。画面上部の登録スポット数には停止中のスポットも含まれます。

- 取得履歴があるスポットは削除できません
- 削除できるのは開催前かつ取得履歴がないスポットです
- 停止しても過去の取得実績は達成数に残ります
- 削除によりスポット数が達成条件を下回る場合は警告が出ます
- 停止中を除く有効スポット数が達成条件以上であることを確認します

## 5. QR、印刷、PDF

イベント入口は「イベント設定」の「イベント入口を印刷」から表示します。各スポットは「スポット管理」からQR確認、SVGダウンロード、個別印刷を行えます。「PDFダウンロード」では全スポットをまとめて出力します。

QR再発行は、URLが共有された疑いなど、古いQRを無効にする必要がある場合だけ実行してください。再発行後は印刷・掲示・配布済みの該当QRをすべて交換します。

ベースURLを変更して復元した場合は、イベント入口と全スポットQRが変わります。すべて再印刷・交換してください。

## 6. 参加・応募集計

「参加・応募」では、参加者、取得、達成者、応募者の件数とスポット別取得数を確認できます。

- 「全参加者CSV」: 未達成・未応募を含む参加者全体
- 「応募者CSV」: 応募した参加者と応募内容

CSVには個人情報が含まれる場合があります。必要な担当者だけが扱い、不要になったファイルは削除してください。抽選と当選連絡はアプリ外で行います。

## 7. 操作ログ

「操作ログ」でログイン、設定変更、スポット操作、バックアップ等の記録を確認できます。不審な操作や障害調査時は、日時、操作、結果を確認してください。ログだけで個人の行為を完全に証明できるものではありません。

## 8. バックアップ

「バックアップ」で現在の管理者情報、イベント、スポット、参加・応募データをZIPへ保存できます。作成には現在の管理者パスワードが必要です。

次のタイミングで取得してください。

- インストール直後
- イベント公開前
- 設定やスポットを大きく変更する前
- アプリ更新前
- イベント終了後

バックアップZIPには個人情報と認証情報が含まれます。公開領域へ置かず、安全な場所で保管してください。

## 9. 復元

稼働中環境での復元は現在のデータをバックアップ時点へ置き換えます。先に現在のバックアップも取得してください。

1. バックアップZIPを選択して検証する
2. 画面下部の「復元内容の確認」で作成日時、URL、スポット・参加者・応募者数を確認する
3. 指定の確認文字と現在の管理者パスワードを入力する
4. 復元後はバックアップ作成時点の管理者パスワードでログインする
5. イベント、スポット、参加者、応募、QRを確認する

新しい環境への復元はブラウザインストーラーから行います。URLが変わる場合はQR全交換の赤い警告を確認してください。

## 10. イベント終了後

1. 応募者CSVと必要な全参加者CSVを保存する
2. 最終バックアップを取得する
3. 個人情報の保管期限と削除方法を決める
4. 不要になった手元のCSVとバックアップを削除する
5. サービスを終了する場合は[アンインストール手順](UNINSTALL.md)に従う
